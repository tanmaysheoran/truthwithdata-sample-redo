How to Use

  1. Enter your numerical data values separated by commas, spaces, or new lines
  2. Optionally enter a custom percentile value (1-99) to calculate
  3. Click "Calculate" to see quartiles, percentiles, and data distribution

Understanding Quartiles & Percentiles

  • Quartiles: Divide your data into four equal parts (Q1, Q2/Median, Q3)
  • Q1 (25th percentile): 25% of data falls below this value
  • Q2 (50th percentile/Median): The middle value of your dataset
  • Q3 (75th percentile): 75% of data falls below this value
  • IQR (Interquartile Range): Q3 - Q1, represents the middle 50% of data
  • Percentiles: Indicate the value below which a given percentage of observations fall
